Supabase Magic Link Authentication

Authenticates against the Supabase Auth REST API (POST /auth/v1/magiclink). Returned tokens are verified with PyJWT against the project's published JWKS (ES256), checking signature, expiry, and the authenticated audience.

Note: When SUPABASE_URL and SUPABASE_ANON_KEY are configured, this sends a real email to the address above. Submitting does not sign you in: the session is established only after you open the link, which returns to /auth/callback for JWT verification. Without those settings the backend reports a simulated dispatch and sends nothing.
